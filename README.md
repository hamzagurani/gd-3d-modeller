# gd-3d-modeller

Gümüşhaneden ürünlerinin 3D modelleri (GLB) — gumushaneden.com ürün sayfalarındaki
`<model-viewer>` bloğu dosyaları buradan çeker (GitHub Pages, CORS açık).

- `modeller/` — canlıda kullanılan modeller (`urun-slug.glb` + `urun-slug.jpg` poster)
- `test/` — boru hattı testi için örnek model (Google model-viewer'ın Astronaut örneği); pilot bitince silinir
